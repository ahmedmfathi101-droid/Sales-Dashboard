## 📌 About The Project (عن المشروع)
This is an enterprise-level, multi-tenant sales dashboard built with **Streamlit** and **PostgreSQL** (Neon Cloud). It is designed to help sales professionals and agents track their daily targets, analyze their performance through AI-driven insights, and manage their shift schedules in real-time.

نظام إدارة مبيعات متقدم مبني باستخدام تقنيات (Streamlit) و (PostgreSQL). يهدف النظام إلى مساعدة موظفي المبيعات على تتبع أهدافهم اليومية، تحليل أدائهم عبر مؤشرات ذكية، وإدارة مواعيد عملهم بكفاءة عالية مع دعم كامل لنظام تعدد المستخدمين (Multi-Tenancy) والعزل التام للبيانات.

## ✨ Key Features (المميزات الرئيسية)
* 🔐 **Multi-Tenant Security:** Secure login system with Row-Level Isolation (Users only see their own data).
* 🧠 **AI-Driven Analytics:** Smart insights predicting end-of-month sales and providing strategic up-selling/cross-selling recommendations.
* 🎯 **Dynamic Targets & KPIs:** Real-time tracking of daily sales targets with interactive Gauge charts.
* 📅 **Smart Shift Scheduling:** A built-in calendar to log upcoming shifts, automatically calculating remaining shift hours dynamically.
* 📥 **Automated Reporting:** One-click export of personalized sales data to Excel (`.xlsx`).
* 🎨 **Bilingual UI / UX:** Fully optimized Right-to-Left (RTL) Arabic interface with a modern Glassmorphism design.

## 🛠️ Tech Stack (التقنيات المستخدمة)
* **Frontend/Backend:** Python, Streamlit
* **Database:** PostgreSQL (Neon Serverless Cloud)
* **Data Manipulation:** Pandas, SQLAlchemy
* **Data Visualization:** Plotly (Express & Graph Objects)
* **Exports:** OpenPyXL
